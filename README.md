### Установка как приложение

**На Android/Windows:**
1. Открой ссылку в Chrome
2. Нажми кнопку "Установить" в адресной строке
3. Приложение появится на home screen 📱

**На iPhone:**
1. Открой ссылку в Safari
2. Нажми Share (внизу)
3. Select "Add to Home Screen"
4. Готово! 🍎
